La segunda actividad consta de construir un diseno de base de datos orientado a una biblioteca, la biblioteca de la universidad si es que te inquieta que no este especificado. Para esta actividad usamos nuestras "Tecnicas de levantamiento de requerimientos" para preguntar a la maestra dulce (empleada de biblioteca) y aclararnos bastantes duda sobre los procesos operativos de la biblioteca. Para hacertela corta, nos hablo de como se acomodan los libros, diferentes tipos de operaciones como prestamos, el formato con el que se registran los libros, los diferentes departamentos que existen, y cuestiones variopintas que me llevaria mucho tiempo escribir aqui.
